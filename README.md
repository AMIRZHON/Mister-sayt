# Mister — кафелерге тауар жеткізу қызметінің сайты

Бір беттік бизнес-сайт: басты бет, қызметтер, жұмыс тәртібі, бағалар, біз туралы, сұрақ-жауап, байланыс және өтінім формасы.
Сайт қазақ тілінде, телефонға бейімделген, күндізгі және түнгі режимі бар.

## Файлдар

```
index.html             — сайттың барлық мәтіні мен бөлімдері
assets/css/style.css   — дизайн: түстер, қаріптер, орналасу
assets/js/main.js      — мәзір, форма → WhatsApp, «қазір ашықпыз» белгісі, түнгі режим
assets/img/favicon.svg — браузер қойындысындағы белгі
```

Ештеңе орнатудың қажеті жоқ: `index.html` файлын браузерде ашсаңыз, сайт көрінеді.

### Жұмыс уақыты

«Байланыс» бөліміндегі тізім «Қазір ашықпыз / Қазір жабықпыз» белгісін де басқарады:

```html
<li data-days="1,2,3,4,5,6" data-open="08:00" data-close="22:00">…</li>
```

`data-days`: 0 — жексенбі, 1 — дүйсенбі, … 6 — сенбі. Уақыт Қазақстан уақытымен (UTC+5) есептеледі.
Атрибуттарды өзгерткенде, сол жолдағы мәтінді де өзгертуді ұмытпаңыз.

## Тапсырыстар қалай келеді

Клиент форманы толтырып, «Тапсырыс беру» батырмасын басқанда, тапсырыс **FormSubmit** (formsubmit.co)
қызметі арқылы `amirkuchakov2002@gmail.com` поштасына автоматты түрде келеді. Хаттың тақырыбы:
«Жаңа тапсырыс M-…». Клиент сайтта «Тапсырысыңыз қабылданды» деген хабарды және тапсырыс нөмірін көреді.

**Бір рет іске қосу керек:**
1. Сайттан (https://amirzhon.github.io/Mister-sayt/) өзіңіз сынақ тапсырыс жіберіңіз.
2. Поштаңызға FormSubmit-тен «Activate Form» деген хат келеді («Спам» папкасын да қараңыз). Хаттағы батырманы басыңыз.
3. Осыдан кейін барлық тапсырыс поштаңызға келеді.

Форма іске қосылмай тұрғанда немесе интернет болмаса, сайт клиентке «Тапсырыс жіберілмеді» деп көрсетеді
де, тапсырысты WhatsApp арқылы жіберуді ұсынады (мәтіні дайын, `data-whatsapp` нөміріне барады).
Сондықтан тапсырыс жоғалмайды.

Поштаны өзгерту үшін `index.html` ішіндегі форманың `data-endpoint="https://formsubmit.co/ajax/…"`
атрибутындағы поштаны ауыстырыңыз. Жаңа поштаны да жоғарыдағыдай бір рет іске қосу керек.

## Интернетке жариялау (GitHub Pages)

1. GitHub-та репозиторийді ашыңыз → **Settings** → **Pages**.
2. **Source** өрісінде *Deploy from a branch* таңдаңыз.
3. **Branch** өрісінде сайт файлдары жатқан тармақты (қазір — `claude/website-creation-s3860h`,
   кейін `main` болуы мүмкін) және `/ (root)` папкасын таңдап, **Save** басыңыз.
4. 1–2 минуттан кейін сайт мына мекенжайда ашылады: `https://amirzhon.github.io/Mister-sayt/`

GitHub Pages ашық (public) репозиторийде тегін, жабық (private) репозиторийде ақылы тарифті қажет етеді.
Өз доменіңізді (мысалы, `mister.kz`) сол **Pages** бетіндегі **Custom domain** өрісінде қосуға болады.

## Технологиялар

Таза HTML, CSS және JavaScript: фреймворк та, құрастыру (build) да қажет емес.
Қаріптер Google Fonts-тан жүктеледі (Fira Sans Extra Condensed, Onest, IBM Plex Mono) — үшеуі де қазақ әріптерін толық қолдайды.

## Слайдшы — презентация құрастыратын бет (`slides/`)

Тақырыпты жазасыз, дизайн мен слайд санын таңдайсыз — дайын презентация шығады. Слайдтарды сол жерде өңдеп,
толық экранда көрсетуге немесе PowerPoint файлы етіп жүктеуге болады.

```
slides/index.html  — беттің қаңқасы (GitHub Pages үшін)
slides/app.css     — қолданба мен слайдтардың дизайны
slides/app.js      — бүкіл логика: жасау, өңдеу, көрсету, жүктеу
slides/icon.svg    — қойынды белгісі
```

Сайт жарияланғаннан кейін мына мекенжайда ашылады: `https://amirzhon.github.io/Mister-sayt/slides/`
(GitHub Pages қай тармақтан жарияланса, `slides/` папкасы сол тармақта болуы керек).

**Мәтінді кім жазады.** Бет Claude ішінде ашылғанда слайд мәтінін Claude жазады. Кәдімгі хостингте (GitHub Pages)
жасанды интеллект қосылмаған: құрылымы дайын үлгі жасалады, жақша ішіндегі мәтінді өзіңіз толтырасыз.
Өз сайтыңызда да AI жұмыс істеуі үшін API кілті сақталатын сервер керек (бұл әзірге жоқ).
